# UI/UX 명세

## 공통 셸
참조 `mycodehive/iacfgeneral_ver3`의 공통 base·CSS·JS를 조사하여 업무 콘텐츠/브랜딩을 제외한 상단 대메뉴, 좌측 중·소 메뉴, 카드·표·입력·버튼 및 라이트/다크 패턴을 재사용한다. 동일 픽셀은 원본/새 화면의 같은 viewport 비교 후에만 주장한다.

| 영역 | 화면 및 동작 |
|---|---|
| 매뉴얼 | 공간 목록 → 공간 트리 → 문서 열람 |
| 문서 열람 | 좌측 트리, 중앙 게시본, 우측 제목 목차 |
| 편집 | Tiptap/Markdown 본문, 자동저장·저장/검토 요청, 서버 정제 미리보기 |
| 승인함 | 정확한 요청 버전, 승인/반려/게시 정책 |
| 문서 설정 | 부모/순서/보관·삭제·복구, 영향 하위 노드 안내 |
| 시스템 | 브랜딩, 계정·그룹, 메뉴, 연결·리소스·바인딩, 감사 |

## 공간 설정 상세
열람/편집/관리·승인 그룹은 체크박스 다중선택. `활성` 및 `본인 문서 승인 허용` 레이블 뒤 체크박스. 노드 설정은 `보관 처리` 레이블 뒤 체크박스와 삭제 액션. destructive action은 POST+CSRF와 영향 설명을 제공한다.

## 상태와 반응형
모바일은 sidebar drawer, 태블릿은 TOC 접기, 데스크톱은 트리·본문·TOC. 표만 필요한 가로 스크롤을 허용하고 페이지를 중첩 스크롤로 만들지 않는다. 빈 공간/검색 없음, 403, 404, form error, 충돌 409를 명확히 표시한다. URL 검색 파라미터로 조회 조건을 유지한다.

## 접근성·보안
모든 입력은 label, 체크박스 그룹은 설명, 버튼은 기능명, 탭은 키보드 탐색, 색상 외 상태텍스트, focus 표시. 외부 링크의 새 탭은 noopener noreferrer. 문서 HTML은 허용 목록 정제 후 표시. 목차는 정제된 실제 제목에서 생성한다.

## 후속 UX
오프라인 복구·드래그 트리·복잡한 블록 서식 보존은 별도 티켓. 기본 자동저장·텍스트 diff·즐겨찾기는 첫 구현 범위. 화면에 버튼만 추가하여 미구현 기능을 완성처럼 보이지 않게 한다. 접근성 AA 적합성과 모바일 완전성을 운영 릴리스 전 Playwright/수동 검증한다.
