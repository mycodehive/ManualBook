# 미확정 항목과 결정

| 순서 | 질문 | 현재 기본값 | 영향/확정 시점 |
|---|---|---|---|
| 1 | 조직 수/인증 | 다중 조직, 고유 슬러그, 로컬 계정·Membership | 최고 관리자 전역 관리, 조직별 관리자·부서·그룹 |
| 2 | 배포 서버·도메인 | Ubuntu/systemd, SQLite 기본·PostgreSQL/MariaDB 선택 | TLS 설정 전 확정 |
| 3 | 규모·동시접속 | 수치 미확정 | 부하 예산·locking·검색 전 |
| 4 | node ACL | 공간 경계+노드 assignment 및 ACL 관리 UI 구현 | deny·상속 회귀 테스트 유지 |
| 5 | 첨부 허용형식·용량·보존 | 구현 .env/validator 기본값 | 실제 업무 보안검토 전 |
| 6 | RPO/RTO/backup 위치 | 미확정, 매일 백업은 제안 | 운영 이전 owner 결정 |
| 7 | 관리자 MFA/SSO | 확장점, 미구현 | 외부 접속 운영 전 |
| 8 | 검색 품질 | 권한 필터된 부분일치 | 한국어 샘플 실측 후 FTS 결정 |
| 9 | 라이선스 | 원본 저장소의 배포 허가 확인 필요 | 외부 배포 이전 |
| 10 | 블록 편집/가져오기/내보내기 | 블록/Markdown MVP, 고급 변환 후속 | 후속 제품 우선순위 |

## 결정 기록
- 현재 사용자의 개발 요청을 근거로 P0 결과와 MVP 구현을 함께 작성한다.
- 참조 플랫폼 공통 셸/설정 구조를 유지하고 기존 업무 데이터·비밀은 복제하지 않는다.
- SQLite를 기본 DB로 사용하며 PostgreSQL/MariaDB는 선택한다. 선택한 DB의 실제 동시성·복구 검증과 기본 회귀 테스트는 구분한다.
- 연결 테스트는 실제 네트워크 API 검증을 하지 않으면 '설정 검증'으로만 표시한다.
- 계획의 모든 기능을 첫 release 완료로 보고하지 않는다.

## 다음 개발 작업 프롬프트
“ManualBook에서 README에 미구현으로 표시한 기능 중 운영 gate를 먼저 처리하라. 선택한 DB의 실제 동시 저장·승인·게시·트리 이동 테스트를 추가하고, 실패한 경로를 중앙 정책/service에서 수정한다. 로그인 속도제한과 private attachment의 초안/게시 권한 경계를 확인한다. 기존 ref UI와 같은 viewport의 스크린샷을 비교하고 차이를 기록한다. 결과를 테스트 증거와 미해결 운영조건으로 구분하여 보고한다.”
