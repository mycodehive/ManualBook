# ManualBook 제품 요구사항

## 범위와 가정
한 설치에 한 조직을 운영하는 독립형 사내 매뉴얼 플랫폼이다. 로컬 계정과 Django 그룹을 사용한다. 사용자 요청에 따라 계획 작성과 첫 구현을 함께 진행한다. 첨부 계획의 계획 전용 승인 절차보다 현재 사용자의 개발 지시를 우선한다.

관리자: 사이트·계정·그룹·메뉴·연결 설정. 공간 관리자/승인자: 공간 권한 및 게시 승인. 작성자: 문서 초안 작성과 검토 요청. 열람자: 승인 게시본만 열람·검색.

## 사용자 스토리와 수용 기준
| 사용자 | 작업 | 검증 가능한 결과 |
|---|---|---|
| 관리자 | 공간 생성, 열람/편집/관리 그룹 체크 | 지정하지 않은 그룹의 직접 URL 접근도 차단 |
| 작성자 | 새 폴더와 문서 작성 | 같은 공간 내 트리, 순환 부모 방지, 서버 검증 |
| 작성자 | 게시 문서를 개정 | 이전 게시본은 유지되고 초안은 일반 직원에게 숨김 |
| 승인자 | 정확한 버전 승인·게시 | 본인 승인 정책과 상태 전이 검증, 이력 유지 |
| 열람자 | 한국어 문서 검색 | 허용된 게시본만 제목/본문 검색 |
| 운영자 | 백업·복원 | DB와 첨부, 암호화 키를 함께 복구하고 게시본 검증 |

## 첫 구현 목표
Enterprise Platform 공통 셸(상단/좌측 3단 메뉴, 동일 폼·표·버튼, 테마), 사용자/그룹 관리, 브랜딩, Connection/DataResource/FeatureBinding, 공간/노드, 로컬 Tiptap/Markdown 편집·정제, 버전·승인·게시, 비공개 첨부, 검색, Markdown/HTML/DOCX/ZIP 가져오기, PDF/Markdown/Space ZIP 내보내기 및 감사로그를 제공한다. 실제 구현 범위는 README와 테스트 결과를 확인한다.

## 후속 범위
블록 편집 고급 서식 보존, 드래그 정렬, 노드별 ACL 관리 UI, 댓글, PostgreSQL FTS 및 한국어 형태소 분석, SSO/MFA, AI/RAG. 전 기능 완료를 첫 구현으로 간주하지 않는다.

## 비기능 목표
한국어 기본 UI, 모바일 탐색·키보드 초점, private media 보호, POST+CSRF 변경, 재현 가능한 uv 환경 및 DB 마이그레이션. 문서 1만/노드 5만은 부하검증 목표일 뿐 측정된 처리 용량이 아니다. 운영 전 동시접속 목표·RPO/RTO·파일 보존기간을 결정한다.
