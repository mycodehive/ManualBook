# 조직별 메뉴 관리

`/o/<조직 슬러그>/menus/`에서 조직 관리자와 사이트 최고 관리자가 관리합니다.
`mycodehive/iacfgeneral_ver3`의 메뉴 관리 기능(참조 커밋 `e26c26ea66f7efa14f94470cfa174761ad17a811`)을 조직 격리 구조에 적용했습니다.

- 이름·코드·내부/외부 URL·상위 메뉴·순서·활성·하위 탭·허용 그룹·작업 폴더 이름·설명을 등록하고 수정합니다.
- 활성/비활성/모두 필터를 제공합니다. 부모가 비활성이면 자식도 비활성으로 조회되며 자식 자체 설정은 유지됩니다.
- 부모 다음에 자식을 표시합니다. 이동 손잡이를 끌어 앞/하위/뒤에 놓으면 하위 메뉴도 함께 이동합니다. 키보드와 터치 환경에서는 선택 폼으로 같은 이동을 적용합니다.
- 최대 3단계, 순환 금지, 같은 부모의 순서 재정렬을 적용합니다. 오래된 화면의 이동 요청은 409로 거절하므로 새로고침해야 합니다.
- 조직의 메뉴 구성을 JSON으로 내보내고 가져옵니다. 버전 1의 `manualbook-menus` 및 원본 `iacf-menus` 형식을 지원합니다. 최대 1MB 및 1,000개 항목이며 같은 코드는 수정하고 파일에 없는 메뉴는 유지합니다.
- 그룹 이름은 현재 조직의 그룹에만 대응합니다. 그룹을 먼저 등록해야 하며 잘못된 그룹·계층·필드가 있으면 전체 가져오기를 취소합니다. 조직 관리자에게는 그룹 제한을 면제하지만 비활성·잘못된 계층·잘못된 권한 구성은 허용하지 않습니다.
- 허용 그룹 안에서는 하나 이상의 그룹 일치가 필요하고, 상위 메뉴 및 이전에 상속된 각 그룹 규칙은 모두 충족해야 합니다. 이동은 기존 상속 규칙을 보존하며 새 상위 메뉴의 규칙도 적용합니다.
- 변경·이동·삭제·내보내기·가져오기는 감사 로그에 기록합니다. 이동과 가져오기는 조직 잠금과 트랜잭션으로 전체 성공 또는 전체 취소됩니다.

서버 절대 경로, 인증 정보 및 다른 조직의 데이터는 내보내지 않습니다. 작업 폴더 이름은 구성 메타데이터이며 서버 폴더를 자동 생성하지 않습니다. URL은 내부 경로 또는 HTTP(S)만 허용하고 외부 메뉴 링크는 새 탭에서 열립니다.

조직 하위 화면은 공통 제목, 설정 탭, 폼, 저장/취소 버튼, 표, 상태 표시와 삭제 확인을 사용합니다. 실제 브라우저 픽셀 비교는 브라우저 다운로드 실패로 검증하지 못했습니다.
